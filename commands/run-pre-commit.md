Задача: довести pre-commit до зелёного состояния.

Контекст:
- Конфиг: !`ls -la .pre-commit-config.yaml 2>/dev/null || echo "нет .pre-commit-config.yaml"`
- Staged-изменения: !`git diff --cached --name-only`

Инструкции:
1. Если pre-commit не установлен в репе — останови и сообщи (не ставь сам без разрешения).
2. Запусти `pre-commit run --all-files` (или `--files` по staged, если правок много).
3. Разбери вывод по каждому проваленному хуку. Авто-фиксеры (black/isort/prettier/end-of-file-fixer) могли уже поправить файлы — пересмотри diff.
4. Для ошибок, требующих ручной правки (flake8/mypy/shellcheck/yamllint) — внеси минимальные хирургические правки строго по сути замечания, без рефактора соседнего кода.
5. Повторяй прогон, пока не станет зелёным или пока ошибка не потребует решения пользователя (тогда остановись и спроси).
6. Не подавляй ошибки через `# noqa` / `--no-verify` без явного разрешения.

Итог: список хуков PASS/FAIL и что чинил.
