### Внешние дешёвые воркеры — OpenRouter (`scripts/or-task.sh`)

Рутину не гонять на подписке — делегировать: `or-task.sh [-m flash|pro|qwen] [-o max_tokens] "бриф" [файл...]`. Ключ читается из локального env-файла (chmod 600, никогда не коммитить). Ответ → stdout, цена вызова → stderr.

| Алиас | Модель | in/out за 1M | Для чего |
|-------|--------|--------------|----------|
| `flash` (дефолт) | компактная модель общего назначения | ~$0.08/$0.18 | саммари, парсинг, конвертации, boilerplate, черновики |
| `pro` | модель среднего класса | ~$1.12/$3.37 | тяжёлые черновики/планы |
| `qwen` | code-специализированная модель | ~$0.07/$0.28 | кодовые правки по точному брифу (самый буквальный) |

Маршрутизация: механика/рутина (single-file ~50 строк, конвертации, черновики) → or-task.sh; обычный код → opus-субагент; сложное/ревью/решения → main. Приватные/корп репы во внешние API не роутить без отдельного решения пользователя. Результат воркера всегда ревьюит main сам (diff/вывод читать, отчёту не верить). Скоупинг чужой работы дороже самой экономии, если его пропустить.

Фоллбэки (тихая замена исполнителя запрещена — проговаривать в чате):
1. API-сбой → 1 ретрай → sonnet-субагент с явной пометкой.
2. Провал качества → 1 ре-бриф той же модели → эскалация на opus; не более одного круга.
3. Cap max_tokens + таймаут + cap на ввод зашиты в скрипт; аномальная цена вызова → стоп и репорт пользователю.
4. 401/402 (ключ протух / баланс кончился) → явно сообщить пользователю, работать на подписке с пометкой в каждой сессии.
5. Обратного авто-фоллбэка вниз нет — понижение только решением main на новой задаче.
